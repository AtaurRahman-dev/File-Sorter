# File Sorter Automation

A Python script that automatically sorts files into folders based on their type (e.g., .csv, .xlsx, .txt, .png).

# Features

Sorts files by extension: .csv, .xlsx, .txt, .png

Creates folders if they don’t exist

Moves files safely without overwriting

Technologies
Python

os and shutil libraries

# How to Use

Clone the repository.

Modify the path in the script to your desired directory.

Run the script:

bash
Copy
Edit
python file_sorter.py
